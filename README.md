# PokéBonk 网页版（离线镜像）

PokéBonk 网页原版的本地镜像。仓库根目录就是游戏根目录，用 Node.js 起一个本地服务即可游玩。

## 运行

需要 Node.js 16 或更高版本。

Windows 双击 `启动本地服务器.bat`，或在仓库根目录执行：

```sh
node server.cjs 8090
```

浏览器打开 <http://127.0.0.1:8090/>。

页面用了 ES module 动态加载和 fetch，必须通过 HTTP 服务访问，直接双击 `index.html` 打不开。

## 操作

| 按键 | 功能 |
| --- | --- |
| `WASD` | 移动 |
| 鼠标 | 转动视角 |
| `Space`（空格） | 跳跃；长按滑翔（飞行宝可梦） |
| `Shift` | 冲刺 / 滑行 |
| `E` | 交互 |
| `Q` | 瞄准 |
| `R` | 终极技能 |
| `Esc` | 暂停 / 继续 |

按键需切换到英文输入法后再操作，中文输入法会拦截 `WASD`、`E` 等按键。

## 流程

游客登录 → 选择初始伙伴 → 进入对局。对局内有技能选择与计时，宝可梦技能自动释放，靠移动躲避与拾取成长。

## 目录

| 路径 | 内容 |
| --- | --- |
| `index.html` | 游戏入口 |
| `assets/` | JS chunk、精灵贴图、3D 模型（`.glb`）、音效与音乐（`.ogg`） |
| `data/` | 游戏数据与语言包（简体中文 / 英文） |
| `icons/`、`social/`、`favicon.ico` | 图标与分享图 |
| `manifest.webmanifest` | PWA 配置 |
| `version.json` | 构建版本号 |
| `server.cjs` | 本地静态服务，含 `/api-proxy` 转发与离线兜底 |

游戏资源全部在本地：35 个 3D 模型、1032 个音频、贴图与数据文件共 5291 个文件、约 97 MB。

## 离线范围

界面、精灵、3D 模型、音乐、数据文件均为本地资源，断网也能加载并开一局。账号存档、排行榜、赛季与新闻走 `server.cjs` 的 `/api-proxy` 访问官方接口；官方不可用时改用本地档案开局，不写官方存档。

语言包保留简体中文与英文，西班牙语为内置兜底。
